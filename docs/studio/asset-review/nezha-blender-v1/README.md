## 已知不足（占位级，不是正式美术）
- 没有贴图，纹样全靠顶点色；脸只有眉眼鼻嘴的简单形，手是连指手套形，没有分指。
- 衣服是贴身的硬壳，没有布料层次；甲裙和腿之间在大幅抬腿时会穿插。
- 还没有动作：只有静置和一个摆出来的英雄姿态。浮动、红绫弹簧、攻击动作要么由玩法轨用程序叠加，要么下一步在 Blender 里做。
- 尚未在天工引擎 0.4.19 里导入验证（蒙皮、骨骼挂件、顶点色、双面材质）。
