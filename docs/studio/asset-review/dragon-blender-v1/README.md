## 已知不足（v1 是占位级，不是正式美术）
- 没有贴图：鳞片只靠顶点色明暗表现，近看是条纹，不是真鳞片。
- 嘴里没有口腔和舌头，张大嘴时能看到空腔。
- 背鳍没有单独骨骼，跟着脊柱动；二阶段「背鳍竖起 1.4 倍」暂时做不了，需要加 12 根鳍骨。
- 眼睑是一块简单的盖片，闭眼效果粗糙。
- 骨骼是 40 节 × 0.4 m，和会上技术美术说的「40 节 × 0.45 m」不同：0.45 m 是把头也算进 18 m 的口径，本版头单独一根骨。程序脊柱曲线按 16 m 龙身 + 2 m 头对接即可。
- 尚未在天工引擎 0.4.19 里实际导入和播放过，需要玩法轨或技术美术做一次导入验证。

## 游动动画（11-06 21:20，`animate_swim.py`）
用法：`Blender --background dragon_king_v1.blend --python animate_swim.py -- <输出目录>`

**原理（和游戏里的程序化脊柱是同一套）**：头沿一条路线前进，身体每一节都走到「头曾经走过的位置」（跟随式）。路线本身带左右摆动和上下起伏，所以起伏会自然地从头传到尾，看起来就是在游。

| 参数 | 值 | 说明 |
|---|---|---|
| 游速 | 4 m/s | |
| 水平摆动 | 波长 9 m、约 0.44 Hz，振幅颈 0.15 m → 尾 0.6 m | 会上技术美术的数值 |
| 上下起伏 | 波长 18 m、约 0.22 Hz，振幅 **±2.0 m**（峰到谷 4 m） | 老板 11-06 21:22 要求在一人高基础上翻倍 |
| 基准高度 | 龙身轴线离涡面 **5.5 m**（随幅度翻倍抬高 1 m） | 波谷时龙身下沿 ≈ 2.75 m，仍 ≥ 2.5 m；波峰时背脊约 8 m，加鹿角和背鳍略超 8 m |
| 头 | 跟着路线转向，俯仰减半 | 看起来更稳，方便以后改成「始终盯着哪吒」 |
| 须、鬃 | 跟着摆，相位逐节滞后 | |

**产出**
| 文件 | 内容 |
|---|---|
| `dragon_king_v1_swim.glb` | 模型 + 3 段原地循环动作（各 4.5 s，可无缝循环）：`Swim`（水平 + 上下）、`Swim_Horizontal`、`Swim_Vertical`。原地游，位移由游戏控制根节点 |
| `swim_side_height.mp4` | 侧视 + 高度标尺 + 2.5 m 受击线 + 哪吒红柱：看上下起伏幅度 |
| `swim_closeup.mp4` | 3/4 近景，深海背景：同时看水平摆动和上下起伏 |
| `swim_arena.mp4` | 52 m 漩涡场俯瞰：龙沿外圈环带绕场游 10 s，中间红柱 = 哪吒 |

**注意**：烘焙动画只用于预览和兜底。游戏里应由代码按同样公式实时生成脊柱曲线，因为受击胶囊和地面预警要读同一条曲线；出招预兆时把波形「相位冻结」。
