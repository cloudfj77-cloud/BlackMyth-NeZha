## 老板确认（16:47）
- 上表的参考点和不参考点全部成立。
- **新增参考点：角色压在矩形框上的「破框」设计**。人物立在一个细线矩形框前，头部、兜帽和披风冲出框外，视觉张力很强。
  - 适用：开始界面、加载画面、结算界面「东海潮平」，也可以给封面构图做参考。
  - 落到本作：哪吒冲出朱红或赤金的细框，飘带甩出框外最能表现张力；龙王一侧可以用墨青铜框，让长躯从框里穿出来。
  - 不适用：战斗 HUD。战斗中要极简，不能挡画面。
