# 参考图库

按对象分目录存放：

| 目录 | 放什么 |
|---|---|
| `nezha/` | 哪吒：形象、服饰、法宝、姿态、悬浮感 |
| `dragon-king/` | 东海龙王 / 东方神龙：体型、头部、龙须龙角、游动姿态、鳞片与配色 |
| `scene/` | 海底龙宫：珊瑚峡道、白玉广场、宫殿、光影、水体氛围 |
| `ui-hud/` | 界面与 HUD 风格 |
| `cover/` | 封面构图、标题字体 |

## 每张图要写的说明
每个目录里各放一个 `notes.md`，每张图写一行说明：

    文件名 | 参考什么（剪影/配色/构图/氛围/材质/动态） | 不要参考什么

## 版权约定
参考图只用来确定方向，**不会作为素材放进游戏**，也不做描摹或贴图。
来自商业游戏（如《黑神话：悟空》）的截图同样只作参考。
