# 第一层 · 总监层（定方向）

## 1. 创意愿景 · 负责人：创意总监 ✅

- **一句话**：3D 第三人称动作 Boss 战。少年哪吒携三昧真火闯入东海龙宫，问罪东海龙王。
- **核心体验**：「水中燃火」。火在海底也不灭，这是本作区别于其他作品的地方。
- **体验目标**：打他痛快，打完心里一沉。
- **基调**：「龙宫沉郁，少年意气」。环境压抑，哪吒本人不压抑。
- **主题**：火对水。哪吒为朱红、橙金，龙王与环境为墨青铜、冰青、深蓝，贯穿配色、特效与封面。
- **风格**：写实东方神话，致敬《黑神话：悟空》的战斗手感与氛围，不使用其官方素材与名称。
- ✅ **全局动态感（老板指令，第 3 场会议定稿）**：画面里没有静止的东西。
  - **两套浮动气质**：哪吒轻灵如火，幅度小、频率快，红绫向上飘，像火苗；环境沉缓如水，幅度大、频率不超过 0.25 Hz，成片同向。
  - **四条底线**：
    1. 浮动只改视觉，不改判定。
    2. 闪烁和收缩只属于地面预警。
    3. 命中顿帧时所有浮动同时停止。
    4. 剪影三要素和 Boss 的预兆姿态不能被浮动打乱。
  - 🟡 **龙王也悬浮，形象为东方神龙：蛇形长躯，在水中游动（老板指令 11:53，11:59 确认）**。原定的「火浮水沉、龙王踏地」作废，龙王与哪吒的对比待重新定义。

## 2. 技术方向 · 负责人：技术总监（暂由技术美术代为把关）✅

- **引擎与平台**：天工引擎 ForgeAX（TypeScript + WebGPU 网页引擎），电脑键鼠，发布到造化平台。
- **起点**：天工引擎 `game-3d` 第三人称模板。游戏目录为 **`nezha-boss`**。
- **性能目标**：集成显卡、1080p、60 帧。泛光效果需实测，不达标就降级。
- **交付原则**：每个里程碑都要先用 forgeax CLI 执行 `project build`，再在构建后的本地预览中用真实输入逐条验收，之后才交给老板试玩。

## 3. 制作计划 · 负责人：制作人 ✅（老板 12:05 批准「双轨 + 新 M1～M5」）

# 第二层 · 部门层（定设计）

## 4. 玩法设计 · 负责人：主策划 ✅

### 4.1 操作

| 按键 | 动作 |
|---|---|
| WASD | 悬浮移动；按住 Shift 飞驰（不能升降，腾空是 Boss 的专属动作） |
| 鼠标 | 旋转镜头（点击画面锁定鼠标，Esc 释放并暂停） |
| R | 锁定 / 解除锁定 Boss（25 米内可锁定，超过 30 米自动解除） |
| 鼠标左键 | 轻攻击，最多三段连击 |
| 鼠标右键 | 按住蓄力，松开重击 |
| Shift（单击） | 风火轮闪身：朝移动方向闪避，没有方向时向后闪避 |
| Q | 服食莲子回血 |
| 1 | 混天绫·缚（定住 Boss） |

### 4.2 哪吒（玩家）规则

- **基础数值**：生命 100，气力 100。
- **气力消耗**：轻击 12/次，重击 30，闪身 20，飞驰每秒 15。
- **气力恢复**：停止耗气力的动作 0.8 秒后，每秒恢复 25。
- **气力不足**：剩余气力不够下一个动作时，该动作不执行（连招中断、不能闪身），HUD 气力条闪烁提示。
- **轻攻击**：三段连击，伤害 8 / 9 / 14。前一段结束后 0.6 秒内再按左键，接下一段。
- **重击**：蓄力 0.3～1.2 秒，伤害从 20 线性增长到 45。蓄满时播放提示音。出招时向前冲 0.5 米（根节点的实际位移，在命中帧之前完成，碰到受击体就停下），这段前冲计入 3 米判定。判定只在命中帧计算一次。
- **命中条件**：Boss 在攻击距离内（轻击 2.5 米，重击 3 米），且位于角色正前方 ±60° 范围内。**距离从 Boss 受击体的表面算起。**距离或方向不对就挥空，没有命中音效，也不造成伤害。
- **风火轮闪身**：持续 0.45 秒，前 0.3 秒无敌，不造成伤害。
- **完美闪避**：在 Boss 攻击命中前 0.2 秒内按下闪身，不受伤，并触发 0.3 秒慢动作、残影和专属反馈，返还 20 气力。
- **闪避失败**：照常扣血，进入 0.4 秒受击硬直，期间不能操作。
- **莲子**（太乙真人所赠）：共 3 枚。每次服食需 1 秒，回复 40 生命；服食期间不能攻击，移动减速。用完后按 Q 只提示「莲子已尽」，不会回血。
- **混天绫·缚**：红绫在 0.2 秒内缠住 Boss（没有飞行弹道），定住 3 秒，期间 Boss 停止一切动作。冷却 20 秒。只能在 Boss 处于锁定范围（25 米）内时释放。
- **锁定**：锁定后，WASD 改为围绕 Boss 环绕移动和前进后退，角色始终面朝 Boss，Boss 身上显示锁定标记。
- ✅ **悬浮规则（第 3 场会议定稿）**：
  - 风火轮底部离海床 0.3 米，平时上下浮动 ±5 厘米。**浮动只作用于模型子节点**；根节点的位移和受击胶囊（0～1.9 米高）固定在海床上，不随浮动移动。
  - Boss 的地面招式一律按水平面判定，预警形状就是伤害区，悬浮不会让哪吒躲开。
  - 不能升降。我方攻击的命中也只看水平距离和角度。
  - 移动速度 5 米/秒，飞驰 9 米/秒；0.1 秒加到满速，松手后 0.15 秒停下（约滑行 0.4 米），转向速度 720°/秒。飘的感觉靠身体前倾和红绫拖尾来表现，位置本身必须跟手。

### 4.3 Boss：东海龙王

> 🟡 **待重新设计（老板指令 11:53）**：龙王应为**东方神龙（蛇形长躯，悬浮游动）**（老板 11:59 确认）。本节原先按「龙首人身、4.5 米、分水叉」设计，形态、尺寸、受击体和招式表现都要重议。以下内容仅作参考。原则保留不变：伤害区、预警、模型实际够到的位置三者一致；地面提示收缩结束的那一帧即命中帧；冰青色预警；二阶段在 50% 血量。


- **基础数值**：生命 800。每招结束后有 1.2 秒破绽可以反击；第二阶段缩短为 0.8 秒。
- **尺寸**：身高 4.5 米，分水叉长 3.5 米，龙尾长 4 米。
- **受击体**：只有一根躯干胶囊（半径约 1 米）。尾巴和叉不设受击体，避免「远处砍尾巴」成为最优解。
- **一致性原则**：伤害区域、地面提示、模型实际能够到的位置，三者必须一致。
- **预兆规则**：
  - 每招都有独特的姿态剪影（举叉竖、甩尾横、伏身低、腾空高）、冰青色地面范围提示，以及一个预兆音效（用来提示镜头外的出招）。
  - 地面提示收缩结束的那一帧就是命中帧。

| 招式 | 触发 | 预兆 | 效果 |
|---|---|---|---|
| 分水叉三连刺 | 距离 < 4 米 | 0.6 秒，夸张地把叉举过头顶，叉尖泛光；地面出现一条窄直线提示 | 三段，每段 10 伤害 |
| 龙尾横扫 | 距离 < 5 米 | 0.9 秒，转身蓄势、甩起龙尾；地面出现 5 米半径扇形 | 18 伤害，带击退 |
| 化龙突进 | 距离 > 8 米 | 0.8 秒，伏身，身后水汽汇聚；地面出现指向玩家的直线 | 裹挟水浪冲刺 12 米，20 伤害 |

- **第二阶段（生命 ≤ 50%）**：
  - 龙吟 2 秒，期间无敌，伴随震屏和环境光变化；HUD 血条在 50% 处有阶段刻度。
  - 整体速度提高 20%。
  - 突进变为连续两次，**第二次重新给预兆**。
  - 新增 **怒海龙吟**：1.0 秒腾空预兆，落点地面出现**圆环**提示（外圈 7 米，内圈在受击体外约 1.5 米，内圈以内是安全区）。落地造成 25 伤害，并向外扩散水浪冲击波。玩家可以贴身躲进安全区换取破绽，也可以远离保命。

### 4.4 战斗流程

1. 玩家从珊瑚礁峡道出发，进入 Boss 场后，入口被旋转的漩涡水墙封住，东海龙王从宫门现身，开始计时。
2. 入口处的海螺长明灯是**检查点**。
3. **玩家死亡**：显示「败」，2 秒内可以按 R 或点「再战」，从检查点快速重试。所有状态完全重置：双方生命、气力、Boss 阶段、莲子次数、混天绫冷却、计时、受击次数、Boss 位置。
4. **击败 Boss**：慢动作定格，龙王说出倒下台词，然后显示结算界面「东海潮平」：
   - 用时、受击次数、完美闪避次数
   - 评价：S（3 分钟内且受击 ≤ 3 次）/ A / B
   - 奖励：技能点（S/A/B 分别为 3/2/1），以及装备「龙王逆鳞」（展示名称和说明）
   - 「再战」按钮

### 4.5 HUD

- **左下**：哪吒的生命条、气力条
- **底部中央**：Boss 名称与生命条，血条带 50% 阶段刻度
- **右下**：莲蓬加 3 颗莲子，显示剩余次数；混天绫·缚的图标和冷却倒计时
- **Boss 身上**：锁定标记
- **提示文字**：气力不足、莲子已尽、混天绫冷却中

## 6. 美术 · 负责人：美术总监

### 6.1 哪吒外观 ✅

- **年龄与体型**：15～16 岁少年，身高 1.65 米，偏瘦但结实。
- **剪影三要素**（不可删）：双丫髻、身后飘动的红色混天绫、比人还长的火尖枪（2.4 米）。验收标准：只看灰模剪影，30 米外也能认出是哪吒。
- **配色**：朱红、赤金、莲白，以火焰橙点缀。朱红只用作服饰本色，不发光；地面特效只用橙金。
- **服饰**：赤红短甲配莲花纹护腕，混天绫缠肩，乾坤圈戴在**右前臂**，赤足，脚踩风火轮。
- **发光规则**：只有混天绫、枪尖、风火轮自发光，并加菲涅尔冷色轮廓光；短甲不发光。
- **法宝表现**：
  - **乾坤圈**：随蓄力分段变亮（只做蓄力反馈，不是加成）。
  - **重击**：枪尖喷出一道火焰面片，长度与 3 米判定距离一致。
  - **风火轮闪身**：火轮一闪，留下短促的橙金拖尾；完美闪避时火轮一次性短爆。
  - **混天绫·缚**：红中带金的绫带缠绕龙王。
  - **混天绫冷却期间**：绫带不消失，而是变暗、下垂、几乎不摆动，金纹从根部向末端逐渐填满；冷却就绪时末端闪光并播放提示音。
- ✅ **悬浮形态（第 3 场会议定稿）**：
  - 哪吒始终悬浮，脚踩常驻的风火轮。
  - **浮动参数**（程序化叠加，由动画师定）：
    - 静止时上下 ±5 厘米、0.8 Hz，叠加 ±1.5° 摆荡（0.55 Hz），两者错相 90°；红绫滞后四分之一周期。
    - 移动时浮动降到 ±3 厘米；飞驰时降到 ±1.5 厘米，并去掉摆荡。
    - 攻击时 0.1 秒内淡出，连招间隙也不恢复；受击时停止浮动，改为一次后仰。
    - 顿帧时浮动和红绫一同停住（读取哪吒自身的时间缩放）。
  - **风火轮三种状态**（靠亮度和形状区分，不闪烁；关闭泛光后仍要分得清）：
    - 平时：三成亮度，火焰内收，无拖尾。
