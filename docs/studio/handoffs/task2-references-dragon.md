## 3. 龙王重新设计会（参考图到位后召开）
- **已定前提**：
  - 老板指令：东方神龙，蛇形长躯，悬浮游动，外观就是龙。
  - 原先「龙首人身、双脚踏地、分水叉」的方案已作废，「火浮水沉」不再成立。
  - 老板 16:29 确认（参考图 `references/dragon-king/dk-01`）：头部造型、背鳍形状、爪子造型要参考；**几乎无爪**；**冰青到墨青的渐变作为龙身主色方向**（需在会上解决和冰青地面预警的区分问题）。
  - 老板 16:47 指令（🟡，建议并入本会议）：**场景不做宫殿，改为斜向的巨大海沟**（参考 `references/scene/sc-01`）；**哪吒浮动幅度加大、飞得更高，飘带要灵动**（参考 `references/nezha/nz-01`）。
- **追加议题**（建议）：
  8. 海沟中的 Boss 战斗区：老板 17:01 定为**海里的漩涡上**（漩涡中心的平整涡面）。要议：涡面直径、旋转速度上限、预警叠在旋转水面上是否清楚、龙沿漩涡水墙和斜壁游动的范围、入场与封口方式。
  9. 哪吒飞高后的参数：离地高度、浮动幅度与频率；与长龙的高度对比，以及「火对水」两套浮动气质怎么重新区分。**红绫可以超过头顶（老板 17:01 拍板）**，只议剪影保护的替代办法。
- **可以沿用的要素**：
  - 白须（体现老父亲的悲剧感）、鹿角、青铜和金色
  - 身上用月白青色，常亮、不闪烁、不参与泛光；只有地面预警才闪烁
  - 二阶段从血量 50% 开始，外观要有能看出来的变化
  - 冰青色地面预警
  - 一致性原则：伤害区、预警范围、模型实际能够到的位置三者一致；地面提示收缩结束的那一帧就是命中帧
  - 台词、命名表和本地化规则
- **议题**：
  1. 体型：长度、粗细、悬浮高度。
  2. 火与水的对比怎么重新表达（参考：「小而快的火 对 大而缓的水」）。
  3. 新招式表（替代原来的三连刺、横扫、突进、怒海龙吟），每招都要有姿态剪影、预兆和判定。
  4. 长躯的受击判定怎么设计。
  5. 镜头：锁定一条长龙时怎么构图。
  6. 技术实现：程序化长躯游动、骨骼、占位方案。
  7. 二阶段的外观变化。
- **建议参会**：创意总监、美术总监、主策划、技术美术、动画师（`animator.md`，自建角色）、叙事总监，最后由制作人收尾。
- **时间要求**：必须在 M3 开工前定稿。M1 的锁定用尺寸可调的长条占位（高 2～8 米、长 4～20 米），新方案如果超出这个范围，要通知主窗口。
