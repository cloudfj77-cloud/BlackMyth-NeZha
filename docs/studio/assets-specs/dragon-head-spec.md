## 1. 交付范围
- **只做龙头**（含下颌、鹿角、白须、鬃毛、颈部接口段约 0.6 m）。**躯干、背鳍、尾、退化小爪不在本单内**，由我方用代码生成。
- 我方会把龙头接到代码生成的脊柱曲线上（全长 18 m、40 节 × 0.45 m、胸径 1.5 m）。

## 2. 造型要求
| 部位 | 要求 |
|---|---|
| 风格 | 写实东方神话，致敬但不模仿《黑神话：悟空》；**不要卡通、不要体素、不要西方龙特征（膜翼、角质盔甲头）** |
| 龙首 | 狭长，长约 2.0 m（含吻部），张口时露獠牙；参考 dk-01 的头部造型和向后炸开的鬃毛。神态是「执念的老父亲」：苍老、威严、悲怆，不狰狞 |
| 鹿角 | 一对，长约 1.2 m，多叉鹿角；青铜质感，尖端旧金 |
| 白须 | 两条主须，每条约 3 m，独立网格、沿须走向分骨，便于我方做弹簧和水流力；颔下可加短须 |
| 鬃毛 | 向后炸开约 0.8 m，分 6～10 簇，可以是卡片网格加透明贴图 |
| 眼 | 可以单独控制闭合（倒下时要闭眼），眼睑至少 1 根骨或 1 个形变目标 |
| 配色 | 底色：冰青到墨青渐变（腹浅背深），龙头亮端不超过 **#7FA295**（Rec.601 去色 Y′ ≤ 150）；鹿角、鳞缘青铜 + 旧金；**禁止大面积高亮冰青**（游戏中冰青是地面预警专用色）。白须偏暖白，不要纯白 |
| 发光 | 预留一张自发光遮罩（月白青纹路，眼周、鳞纹），亮度由我方控制在三成，一阶段 30%、二阶段 45% |

## 3. 技术规格
| 项 | 要求 |
|---|---|
| 格式 | **glTF 2.0（.glb）**，Y 轴向上，单位米，PBR 金属度/粗糙度工作流 |
| 面数 | **龙头（含角、须、鬃）≤ 12,000 三角面**（整条龙预算 ≤ 25,000，躯干留给代码生成） |
| 贴图 | 2048² 以内：底色、法线、金属度/粗糙度/AO、自发光遮罩；鬃毛和须可用一张 1024² 透明图集 |
| 骨骼 | ≤ 30 根：颈部接口 2 根（与我方脊柱首节对接）、头 1、下颌 1、眼睑 2、须每条 6～8、鬃 4～6 簇根骨；全部命名规范（英文、无空格），不需要动画 |
| 姿态 | 直身静置：龙头朝 +Z，闭口，须自然下垂，根节点在颈部接口截面中心 |
| 接口 | 颈部接口截面为圆形，直径 **1.5 m**（与胸径一致），截面顶点 16 或 24 个、均匀分布，方便我方缝合；附一张截面顶点顺序说明 |
| 形变目标（可选） | 张口、怒张鬃毛（二阶段用） |

## 4. 验收（我方在天工引擎内实测）
1. glb 在天工引擎 0.4.19 正常导入，材质与贴图无丢失。
2. 接到代码龙身后，跑 0.6 m 行波和半径 2.5 m 盘绕，颈部接缝不开裂、不扭麻花。
3. 去色截图中，龙头最亮受光面的灰阶比地面预警至少低 30。
4. 灰模剪影 30 m 外能认出「头 + 鹿角 + 须」这一簇。
5. 须、鬃、眼睑骨骼可以被程序驱动；眼睛能闭合。
6. 总面数、贴图尺寸、骨骼数不超标。
