# 发版主观评审表（v1.4.0 §8.2 移植）

> 用法：每次发版前，`node qa/gate.cjs` 全绿后，逐张看 `nezha-boss/artifacts/gate/*.png`（加上本轮新功能的实机截图），按下表 1～5 分打分。**任一项 < 3 分判定不通过，修好再评**，不交付。
> 发版脚本：`nezha-boss/scripts/release.sh <patch|minor|major> "说明"`——门禁不过会自动中止。

## 评分标准
| 维度 | 5 分标准 | 不通过信号 |
|---|---|---|
| 剪影识别 | 远景 30 m 能一眼认出哪吒 / 敖丙（长龙）/ 夜叉 | 角色糊成一团、无标志物 |
| 色彩关系 | 主角红金 vs 敌人冰蓝 / 墨绿，冷暖对立清楚 | 主角与场景同色 |
| 层次纵深 | 近景栈道 / 中景礁石龙柱 / 远景龙宫海蚀柱三层分明，远景被雾吃掉饱和度 | 远景和近景一样清晰、像贴片 |
| 材质可信 | 湿礁石有反光、木板有盐渍、冰晶通透、金属有环境反射 | 纯色塑料感 |
| 动态生命 | 飘带 / 火焰 / 海浪 / 飞沫 / 灯火全在动，角色从不静止 | 任何时刻画面凝固 |
| 打击反馈 | 命中有停顿、震屏、火花、音效 | 打了没感觉 |
| 预兆可读 | 每招都看得出「要打哪儿」 | 突然掉血不知原因 |
| UI 克制 | HUD 不遮主体，信息完整；中文版中英双语不挤 | 遮挡角色或 Boss |
