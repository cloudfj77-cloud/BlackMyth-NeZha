# 会议简报：《白神话：哪吒》角色设计会 · 第 1 场「哪吒：速览 / 概念 / 外观」

## 项目背景
- 游戏：《白神话：哪吒》（英文 White Myth: Nezha），写实东方神话风格的 3D 第三人称动作 Boss 战，单场 Boss，网页游戏，电脑键鼠。
- 引擎：天工引擎 ForgeAX（AI 原生 TypeScript + WebGPU 网页引擎），发布到腾讯造化平台。
- 团队：独立小团队 + AI，美术资源是最大风险。写实角色模型和整套动作需要从造化素材库获取、AI 生成 3D 模型，或先用占位模型，后期再替换。
- Boss：东海龙王（龙首人身、龙鳞铠甲、分水叉，有龙尾横扫招式）。
- 场景：海底龙宫。主角在海床上行走，不游泳；先走珊瑚礁峡道，再进入白玉前庭广场的 Boss 场。
- 长期规则：所有游戏必须中英双语，并做中英两版封面；所有里程碑都要在构建后的本地预览中用真实输入验收玩法。
- 完整需求文档：/Users/cloud/WorkBuddy/2026-11-04-15-19-29/game-spec-nezha-boss.md（可读，禁止修改）
- 已知问题：需求文档沿用了悟空的道具（葫芦、定身术），且缺少角色设计。本次会议就是为了补上角色设计。

## 已定的玩法数值（本会不改数值，只讨论设计）
- 玩家：生命 100，气力 100。三段轻击伤害 8/9/14，命中距离 2.5 米；蓄力重击伤害 20~45，命中距离 3 米；命中需在正前方 ±60° 以内。
- 闪避持续 0.45 秒，前 0.3 秒无敌；命中前 0.2 秒内闪避算完美闪避。
- 回血道具 3 次，每次回 40；定身 3 秒，冷却 20 秒。
- 操作：WASD 移动、鼠标转视角、R 锁定、左键轻击、右键蓄力、Shift 闪避或奔跑、Q 回血、1 定身。

## 本场议程：哪吒的速览、概念、外观
主持人（WorkBuddy）提出的初稿如下，供讨论，不是定论：

1. **故事背景**
   - A. 下海问罪：龙王水淹陈塘关，哪吒独闯龙宫要龙王收手（主持人倾向此项）
   - B. 了结旧怨：哪吒打死了龙王三太子敖丙，龙王为子报仇步步紧逼，哪吒入海做个了断
   - C. 不讲故事，纯粹打 Boss
2. **年龄形象**：少年 15～16 岁（主持人倾向）/ 孩童约 7 岁（最贴传统）/ 青年
3. **外观**
   - 身高 1.65 米，偏瘦但结实
   - 远处可辨认的轮廓：双丫髻 + 身后飘动的红色混天绫 + 比人还长的火尖枪
   - 配色：朱红、赤金、莲白、火焰橙，与龙王的蓝白青铜形成「火对水」的对比
   - 服饰：赤红短甲配莲花纹护腕，乾坤圈戴在颈或臂上，赤足，脚踝有小火轮装饰
   - 火尖枪长 2.4 米，与 2.5 / 3 米的命中距离一致
4. **用标志物替换悟空道具**（数值不变）
