# M1 开工前补数 · 主策划发言实录（2026-11-05 13:00 前后）

> 来源：M1 开工评审制作人决议「海草数量、镜头最小距离由主策划在开工前补齐」。由玩法轨（子窗口 1）召集，单角色发言，结论纳入 `design/milestones/M1-prep-plan.md`，待老板拍板。老板拍板前不改设计文档。

## 主策划
（数值全部进 tuning.json；镜头数值按竖直 FOV 55°、16:9 推导，水平半角 42.8°，改 FOV 须重算最小距离）

**1. 海草：M1 默认 480 株（上限 1200 的 40%）**
- 峡道 240：沿两侧礁壁成丛（每丛 8～15 株），中线两侧各留 1.5 m 空道；株高 ≤ 1.2 m，低于镜头焦点。
- 广场边缘 180：只种半径 16～20 m 环带，宫门、入口缺口不种，半径 16 m 内为 0。
- 远景 60：海沟岩壁脚下稀疏种。
- 理由：M1 只验证管线（实例化、≤ 0.25 Hz、成片同向、绘制调用不随株数增长）；珊瑚、宫殿 M3～M4 进场会抢同一块预算，先留 60%；占位网格面数与正式素材不同，种满 1200 只会给假安全感。
- 与 M5：三组各一个实例批次、各一个株数参数，M5 降级第 4 步只动远景组；M1 交付记录 0 / 480 / 1200 三档 p95。
- 可调 0～1200，推荐 360～600。海草不进镜头射线；石柱验收点 2 m 内不种。

**2. 镜头最小距离：1.2 m（从焦点算）**
- 焦点：根节点上方 1.6 m（悬浮肩高 0.3 + 1.3），挂在根节点上，不随浮动；右肩偏移 0.6 m 另加。
- 推导：1.2 m 时哪吒中轴偏画面中线 30°、左缘约 39°（< 42.8°），纵向覆盖 1.06～2.14 m，双丫髻、红绫、枪上段在画内；与后飘红绫仍隔约 0.4 m。低于 1.0 m 头部出画。前作 0.45 m 不能沿用。
- 防穿墙：球形投射，留边 0.3 m；只检测礁壁、宫墙、海床；忽略石柱（走镂空）、海草、颗粒、锁定目标。
- 到最小距离仍不够时（不穿墙 > 不进模型 > 可辨认）：① 背贴墙：镜头沿墙上抬最多 1.05 m（俯角 60°），转俯视，离焦点 ≥ 1.2 m，偏航与 WASD 不变；② 视线被挡：不再拉近，遮挡物按石柱规则镂空；③ 关卡约束：通行区内不出现低于 3 m 的顶部遮挡。
- 可调 1.0～1.6 m。

**3. 镜头手感默认值**：自由距离 5.0 m（4.0～6.0）；锁定距离 6.5 m（5.5～8.0），注视点取连线 30%；焦点高度自由 1.6 / 锁定 1.8 m；FOV 竖直 55°；俯仰 仰 25°～俯 60°，默认俯 12°；灵敏度 0.10°/像素，无加速无平滑；拉近瞬时；回弹停 0.1 s 后 0.4 s 缓出。

**4. 需老板拍板**：① 背贴墙极端情况：推荐「上抬俯视」（备选「贴近 + 哪吒淡化」与暗处找哪吒冲突）；② 1200 株压测只记录不卡关，p95 > 5 ms 立即上报；③ 自由镜头 5.0 / 5.4 m 由老板试玩一键切换决定。

结论：M1 海草默认 480 株（240 / 180 / 60，可调 0～1200）；镜头最小距离 1.2 m（焦点 1.6 m，可调 1.0～1.6）；三项请老板拍板。
