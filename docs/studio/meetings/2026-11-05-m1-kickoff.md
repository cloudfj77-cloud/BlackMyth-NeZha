## 1. 主策划
结论：有条件同意开工。
- 砍掉气力条：气力属于战斗资源，M1 没有攻击和闪身，调不出意义，计划表里也排在 M2。M1 的飞驰先不限时。
- 补 Shift 判定：单击为闪身，按住为飞驰，按住阈值现在就定（建议 0.2 秒）。否则 M2 加入闪身时，飞驰的起步手感会被改动。
- 锁定用的占位目标做成尺寸可调的长条（高 2～8 米、长 4～20 米），并补上「25 米内可锁定、30 米外自动解除」。两端尺寸都要通过第 1 条，这样龙王怎么重新设计都推翻不了 M1。
- 调参：开发版加调试面板，移速、加减速、转向、镜头距离、浮动参数都能实时调，参数放在外部文件里。
- 可测性：移动数值不在过关清单里，要补一条（误差 ±5%）。「帧率稳定」「最小距离」「少量海草」都要给出具体数字。
- 请 QA 负责人回应：0.1 秒加速、0.15 秒停下，能不能自动测准？

## 2. 技术美术（兼代技术总监）
结论：有条件同意开工。
- 开发顺序：
  1. 改造模板的角色控制器：根节点贴地，模型子节点抬高 0.3 米，补上加减速和 720°/秒 转向。
  2. 右肩偏移镜头，加射线检测拉近。
  3. 浮动与红绫。
  4. 锁定。
  5. 镂空渐隐。
  语言表与造化 SDK 并行开发。
- 红绫：M1 先用程序化条带加弹簧点链，参数与之后的骨链共用。
- 风险：0.4.19 的自定义材质尚未验证，先花半天做试验。如果做不出来，先用 35% 透明度的半透明材质顶替镂空，不改用镜头拉近（石柱密集处镜头会抖）。
- 条件一：第 21 条在 M1 阶段改为代理基线：先确认运行在真实 GPU 上，1080p 下单帧耗时 ≤ 5 毫秒（集显约慢 3 倍），绘制调用 ≤ 300。集显实测放到 M5。
- 条件二：参数集中放在 tuning.json；UiAsset 调试面板打开时释放指针锁定；实时数值通过 registerRead 提供给 QA 读取。
- 请美术总监回应：灰盒阶段用半透明顶替镂空，能否接受？（美术总监未参会，由创意总监代答。）

## 3. QA 负责人
① 能测准，但不依赖真实时钟：通过 registerRead 读取带游戏时间戳的速度数据，再用 play.advance 逐帧复核。指标：0.1 秒内达到满速的 95%，0.15 秒内停下，容差 ±1 帧。
② M1 过关清单（括号内为对应截图名）：
- 移速 5 / 9 米/秒、转向 720°/秒，容差 ±5%（speed）
- 模型距根节点 0.3 米；静止浮动 ±5 厘米、0.8 Hz，容差 ±10%；海草摆动 ≤ 0.25 Hz（hover）
- 胶囊位移 ≤ 1 毫米（capsule）
- 贴墙时不穿模；穿过石柱时 0.2 秒内不透明度降到 ≤ 0.4，哪吒可见面积 ≥ 90%（wall / pillar）
- 长条目标两端尺寸分别为 2×4 米、8×20 米，环绕 12 个角度均完整入画（lock）
- 接触光恒定，偏离根节点 ≤ 1 厘米（glow）
- 身高 1.65 米、枪长 2.4 米，容差 ±3%（silhouette）
- 英文环境无中文残留，伪本地化无溢出（lang）
- 控制台报错为 0（console）
- 运行在真实 GPU 上，1080p 帧耗时 p95 ≤ 5 毫秒，绘制调用 ≤ 300（perf）
③ 需人工判断的项：剪影辨识度、半透明是否可替代镂空，由截图评审；跟手感由老板试玩。

## 4. 本地化负责人
结论：有条件同意。推荐直接使用引擎内置的 i18next：复数、回退、不刷新切换都已现成；如果自己写，M4 加字幕时必然返工。
1. 键名按「区域.界面.用途」分层；术语单独放一个命名空间，台词中引用术语；缺失的键回退英文，不暴露键名。
2. 浏览器语言为 zh 开头时显示中文，其他显示英文。玩家手动选择的语言是否需要记住，请老板拍板。
3. 开始界面和暂停界面都要放语言切换按钮（草案漏了暂停界面）。
4. 调试面板仅存在于开发版，不做双语；QA 检查中文残留时跳过调试面板。
5. 中文字体在构建时按语言表自动裁剪字符集；英文字体须包含 ’ 和 —。
6. 伪本地化：开发版增加 pseudo 语言，把英文加长 30% 并加括号，用来查找硬编码和截断。
返工风险：JSON 无法写注释，M1 就要定好上下文说明放在哪里；切换语言的事件要能通知到封面等非 UI 模块。

## 5. 创意总监（关口把关，并代美术总监回答）
① 接受用半透明代替镂空，但只作为灰盒阶段的兜底：要保留描边，不能遮挡哪吒的火光；进入正式美术前换回抖动镂空。
② 「水中燃火」靠冷暖对比来传达。M1 必须具备：风火轮平时形态（三成亮度、橙金自发光）、红绫自发光并分两股向上飘、接触光、由近到远逐渐变暗的深蓝海水雾色、广场上一道缓慢晃动的光束。环境全部用冷色，暖色只留给哪吒。焦散、尾迹、轮廓光可以暂缓。补一项截图评审：在峡道暗处能一眼找到哪吒。
③ 对各方意见无异议；长条占位目标正好对应蛇形龙身，支持。
④ 有条件通过：上述视觉项需加入过关清单。
